# Instalación del Chat Web de Proyecto Compás

## Archivo modificado
- `index.html`

El widget fue colocado una sola vez, inmediatamente antes de `</body>`.

## Subida a GitHub
1. Entra al repositorio `proyecto-compas-web`, rama `main`.
2. Usa **Add file → Upload files**.
3. Sube únicamente `index.html`.
4. Confirma el reemplazo del archivo existente.
5. Commit sugerido:
   `Instalar chat web conectado con Compás One`

## Limpieza del repositorio
Consulta `ELIMINAR_DEL_REPOSITORIO.txt` y elimina solamente los elementos indicados.

## Prueba
Después de publicar:
1. Abre `https://proyectocompas.com` en una ventana privada.
2. Busca el botón flotante del chat.
3. Registra un contacto de prueba.
4. Confirma que aparezca en Compás One → CRM y Conversaciones.
