# Proyecto Compás — versión corregida para GitHub Pages

Esta versión coloca todas las imágenes en la raíz del repositorio para evitar errores al subir carpetas desde el navegador.

## Publicación

1. Descomprime el ZIP.
2. Sube todos los archivos directamente a la raíz del repositorio.
3. No subas el ZIP ni la carpeta que lo contiene.
4. Activa GitHub Pages desde `main` y `/ (root)`.

El archivo `index.html` y todas las imágenes deben verse en la primera pantalla del repositorio.
