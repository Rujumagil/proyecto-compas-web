## Publicar en GitHub

1. Crea un repositorio público llamado `proyecto-compas-web`.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. No subas el archivo ZIP; sube los archivos descomprimidos.
4. Entra en `Settings → Pages`.
5. Selecciona `Deploy from a branch`.
6. Elige la rama `main` y la carpeta `/ (root)`.
7. Guarda y espera la publicación.
