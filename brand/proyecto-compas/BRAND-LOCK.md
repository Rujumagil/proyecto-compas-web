# Proyecto Compás Evolution — Identidad oficial

La geometría del isotipo de Proyecto Compás está congelada.

## Reglas
- No redibujar, estirar, inclinar, recortar ni recomponer el isotipo.
- Mantener siempre las proporciones del arte maestro aprobado.
- No usar degradados dentro del logotipo.
- Colores web oficiales derivados del arte aprobado:
  - Azul corporativo: `#003366`
  - Dorado corporativo: `#D7A21B`
- Solo se permiten cambios de tamaño, formato y aplicación monocromática autorizada.
- Para fondos oscuros usar `logo-horizontal-oscuro.svg`.
- Para fondos claros usar `logo-horizontal-claro.svg`.
- Para favicon o iconos usar únicamente el isotipo.

Los SVG de esta carpeta se derivaron del arte maestro aprobado para uso web escalable.
