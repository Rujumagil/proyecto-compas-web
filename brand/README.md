# Identidad oficial — Proyecto Compás Evolution

Los archivos de identidad contenidos en esta carpeta son activos oficiales de marca.

## Regla de integridad

El isotipo y los logotipos aprobados no deben redibujarse, deformarse, recortarse, reordenarse ni reinterpretarse. Deben conservar exactamente su geometría, proporciones, relación entre piezas y calidad visual.

Solo se permiten aplicaciones previamente aprobadas de color, cambios de tamaño manteniendo proporción, optimización de formato sin pérdida perceptible y adaptación de fondo conforme a las variantes oficiales.

## Colores corporativos de referencia

- Azul corporativo: `#0B2A5B`
- Dorado corporativo: `#D7A21B`

Para implementación web, reutilizar siempre los archivos oficiales existentes en esta carpeta en lugar de reconstruir el símbolo con CSS o formas nuevas.
